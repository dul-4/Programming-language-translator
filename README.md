PolyCode is an experimental web UI prototype for side-by-side code snippet viewing and basic syntax text substitution. It uses simple string pattern matching to convert basic Python instructions into equivalent C++ formats, featuring a basic simulated text terminal for output display.
## Description

PolyCode is a simple web prototype that processes and translates basic text and code snippets through user input, focusing purely on the visual interface and basic string manipulation.

## Getting Started

### Dependencies
* A modern web browser (Google Chrome, Firefox, Microsoft Edge, Safari).
* No backend environment or Node.js installation required (runs 100% on the client side).

### Executing program
* Open the `index.html` file directly in your web browser or use a local server (like *Live Server* in VS Code).
* Write your code or select a preset example, click the run button, and watch the output appear in the terminal.

## Help

If the terminal fails to respond or you run into any issues executing advanced commands, make sure to check your browser's developer console (`F12`) to verify there are no script blockages.
